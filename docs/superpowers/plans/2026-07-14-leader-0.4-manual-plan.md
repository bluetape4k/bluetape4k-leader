## 한국어 해설

4. Generate bilingual project landing pages, then replace scaffold prose with source-backed Leader-specific content.
5. Write overview, selection, lifecycle, failure, operations, framework, backend, and learning-path chapters.
6. Turn all 17 examples into workshop-grade pages and provide progressive learning paths.
7. Create five dark SVG/PNG diagram pairs and run checklist plus full-size visual review.
8. Update README and AGENTS manual ownership/validation guidance, keeping dependency selection on the central ecosystem BOM.
9. Run manual contracts, Ruby tests, Gradle inventory export, link checks, Korean prose review, and diagram checks.
10. Create a Lore commit and PR with issue metadata parity, use documentation-only CI, merge after live green checks, and synchronize `develop` safely.
