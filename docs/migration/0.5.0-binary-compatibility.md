# 0.5.0 JVM 바이너리 호환성

이 문서의 게시 전 호환성 판단은 `2026-08-01` KST에 기록한 역사적
`as-of` 스냅샷이다. 당시에는 `0.5.0`이 아직 릴리스되지 않았고, 게시된
`0.4.0` 아티팩트를 기준으로 호환성을 확인했다. 현재 릴리스 상태는 아래
게시 후 정리 절을 따른다.

## 현재 릴리스 상태

`0.5.0`은 다음 provenance로 게시되었다.

- Git tag [`0.5.0`](https://github.com/bluetape4k/bluetape4k-leader/releases/tag/0.5.0)
  는 커밋 `721a9a3808f67489d2bdb8177734325981c24977`을 가리킨다.
- GitHub Release [`0.5.0`](https://github.com/bluetape4k/bluetape4k-leader/releases/tag/0.5.0)은
  2026-08-06에 게시되었다.
- 대표 BOM POM
  [`bluetape4k-leader-bom:0.5.0`](https://central.sonatype.com/artifact/io.github.bluetape4k.leader/bluetape4k-leader-bom/0.5.0)이
  Maven Central에 게시되어 있다.

아래의 바이너리 호환성 비교는 게시 후에도 동일하게 `0.4.0` Maven Central
기준선을 사용한다. 기준선 버전과 현재 릴리스 버전은 서로 다른 의미이므로
혼동하지 않는다.

## 게시 전 as-of 스냅샷 (2026-08-01 KST)

## 결정

안정적인 JVM 진입점은 소스 호환 오버로드를 통해 보존된다.

- `LeaderProperties`는 게시된 10개 인자 생성자, copy 메서드, 처음 10개의
  `componentN` 메서드를 유지한다.
- `LeaderObservabilityProperties`는 2개 인자 생성자와 copy 메서드를
  유지한다.
- `HazelcastLock`과 `HazelcastSuspendLock`은 2개 인자 생성자를 유지한다.
- Spring metrics, Actuator endpoint, AOP property bridge는 기반 계약이
  안정적인 경우 기존에 게시된 JVM 메서드를 유지한다.

반복 가능한 검사는 다음과 같다.

```bash
./gradlew checkBinaryCompatibility --no-configuration-cache --console=plain
```

이 검사는 게시 가능한 16개 라이브러리 아티팩트를 `0.4.0` Maven Central
기준선과 비교한다. `examples/*`, `benchmark`, BOM은 게시되는 런타임
아티팩트가 아니므로 제외한다.

## 분류

이 게이트는 모든 japicmp 결과를 보고한다. 다음 항목만 의도된 구현 잡음으로
분류한다.

- Kotlin 컴파일러가 생성한 inline/lambda 클래스와 AspectJ closure 클래스
- Kotlin 컴파일러가 생성한 synthetic accessor 메서드(`access$...`)로, 다른
  생성 클래스에 private 구현 세부 사항을 노출하는 메서드
- 제네릭 Kotlin override에 대해 생성되는 JVM bridge 메서드
- `io.bluetape4k.leader.*.internal` 아래의 클래스

그 밖의 `!` 보고는 명령을 실패하게 하며, 해당 항목을 복원하거나 명시적인
마이그레이션 결정과 함께 이 문서에 추가해야 한다. Serializable model의
`serialVersionUID` 진단은 메타데이터 변경으로 원시 보고서에 남긴다. 이는
API 진입점 제거가 아니며 바이너리 게이트를 조용히 통과시키지 않는다.

현재 `0.5.0`에 대해 의도적인 public 재컴파일 요구 사항은 승인되지 않았다.
