# 0.5.0 한국어 현지화 인벤토리

이 문서는 `0.5.0` 한국어 현지화 작업의 기준 범위를 정의한다. GitHub
issue와 PR 제목/본문은 repository 규칙에 따라 English로 유지하지만,
대상 repository 문서와 Kotlin KDoc/property comment는 후속 PR에서
한국어로 재작성한다.

## 명령

```bash
ruby scripts/localization/korean_localization_inventory.rb summary --format markdown
ruby scripts/localization/korean_localization_inventory.rb list --kind documentation
ruby scripts/localization/korean_localization_inventory.rb list --kind kdoc
ruby scripts/localization/korean_localization_inventory.rb validate --kind all
ruby scripts/localization/korean_localization_inventory.rb validate --kind all --fail-on-violations
ruby scripts/localization/korean_localization_inventory_test.rb
```

후속 현지화 PR에서는 담당 bucket을 한국어로 재작성한 뒤
`validate --fail-on-violations`를 사용한다. 이 inventory PR은 후속 PR이
아직 반영되기 전의 기준선을 기록하므로, repository 전체를 즉시 실패시키지
않는다.

## 범위 수량

| 대상 | 수량 |
|---|---:|
| 단일 언어 문서 | 359 |
| KDoc/property 검토 대상 Kotlin source file | 785 |

현재 전체 baseline은 `ruby scripts/localization/korean_localization_inventory.rb validate --kind all` 기준
`1483`개 violation이다. 후속 PR은 자기 bucket을 재작성한 뒤 같은 명령에
`--fail-on-violations`를 붙여 담당 범위를 게이트로 사용한다.
