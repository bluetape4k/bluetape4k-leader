# 이슈 248/229 예시

## 맥락

Milestone 0.1.1에는 두 가지 채택 예가 필요했습니다.

- `K3sServer.Launcher.k3s`를 사용한 Kubernetes Lease 리더 선출.
- 분산 Bucket4j 속도 제한과 결합된 Redis 리더 선택.

## 결정

둘 다 게시되지 않은 예시로 유지하세요.

- `examples/k8s-lease`는 Fabric8 유형의 임대 연습을 소유하고 `k8s` 태그가 지정된 전용 `k8sTest` Gradle 작업에서 K3s 컨테이너 테스트를 격리합니다.
- `examples/rate-limiter`는 단일 노드 디스패치를 위해 기존 Redis `LettuceLeaderElector` 패턴을 재사용하고 집계 API 할당량을 위해 Lettuce Bucket4j 프록시를 통해 `DistributedSuspendRateLimiter`를 사용합니다.

## 결과

예제는 Gradle 설정, CI 경로 필터, 일반 CI 테스트 작업 및 예약/수동 예제 워크플로에 등록됩니다. 일반 CI는 경량 `k8s-lease:test` 레인을 실행합니다. 권한 있는 K3s 승인 테스트는 `examples:k8s-lease:k8sTest`를 통해 실행됩니다.

## 검증

- `actionlint .github/workflows/ci.yml .github/workflows/examples.yml`
- `./gradlew :examples:k8s-lease:test :examples:rate-limiter:test --no-daemon`
- `./gradlew :examples:k8s-lease:k8sTest --no-daemon`
- `./gradlew build -x test -x koverVerify --parallel --no-daemon`

IntelliJ MCP에서 작업 트리를 사용할 수 있게 된 후 터치된 Kotlin 예제 파일에 대해 IDE 진단을 검증했습니다. 파일은 `problemCount=0`를 보고했으며 빌드 오류는 없습니다. 파일이 편집기에서 열리지 않았기 때문에 파일 분석이 최신이 아니므로 Gradle 컴파일 및 테스트가 기본 검증으로 남아 있습니다.

## 미래의 에이전트

더 많은 예제 모듈을 추가할 때 `settings.gradle.kts`, `.github/workflows/ci.yml`, `.github/workflows/examples.yml`, README 로케일 쌍 및 짧은 강의를 한 번에 업데이트하세요. 실행기 계약이 명시적으로 지원하지 않는 한 기본 CI 경로에서 권한 있는 컨테이너 테스트를 유지하세요.
