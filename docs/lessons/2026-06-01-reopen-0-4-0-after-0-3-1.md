# 리더 0.3.1 이후 0.4.0 다시 열기

## 맥락

`0.3.1` 패치 릴리스는 일시적으로 `baseVersion`를 `0.4.0`에서 `0.3.1`로 다시 이동하여 태그 트리거 릴리스 워크플로가 `gradle.properties`에 대해 태그 버전을 검증할 수 있도록 했습니다.

## 결정

`0.3.1` 태그 바로 다음에 `0.4.0` 개발 라인을 다시 열고 워크플로우를 릴리스하여 새 작업이 실수로 다른 0.3.x 아티팩트를 게시하지 않도록 하세요.

## 결과

공개 README 좌표는 안정적인 최신 `0.3.1`에 유지되고 빌드 라인은 `baseVersion=0.4.0`로 돌아갑니다.

## 검증

- `0.3.1` 태그가 릴리스 준비 커밋에서 푸시되었습니다.
- `0.3.1` GitHub 릴리스는 릴리스 워크플로에 의해 생성되었습니다.

## 향후 지침

이미 열려 있는 마이너 개발 라인에서 만들어진 패치 릴리스의 경우 항상 패치 릴리스에 태그를 지정한 후 개발 `baseVersion`를 복원하십시오.
