# Issue #521 Contention Benchmarks

## Context

Issue #521 needed contention and skip-path benchmarks for single-leader
electors after the group-semaphore benchmark work. The acceptance criteria
required elected and skipped outcomes to be visible, blocking and suspend paths
to be comparable, and at least one benchmark to prove skipped actions are not
executed.

## Decision

Keep remote/shared backends in `BlockingLeaderContentionElectorBenchmark` and
`SuspendLeaderContentionElectorBenchmark`, then split local baselines into
local-only classes. Local electors only contend when the same elector instance
shares in-process lock state, so putting local into the remote/shared factory
shape produces misleading skip behavior.

Local suspend `waitTime=0` was intentionally excluded from local parallel rows.
The implementation uses `withTimeoutOrNull(0)`, so immediate free acquisition
can time out before meaningful contention is measured. Remote suspend immediate
skip remains covered by the held-lock scenario.

## Outcome

The benchmark setup verifies that held-lock skip paths return skipped results
without executing the action body. README and benchmark report now include raw
JSON, rendered SVG/PNG charts, the full 43-row snapshot table, and interpretation
for immediate skip versus positive-wait contention.
