# 이슈 #521 경합 벤치마크

## 맥락

Issue #521에는 그룹 세마포어 벤치마크 작업 후 단일 리더 선거인에 대한 경합 및 경로 건너뛰기 벤치마크가 필요했습니다. 승인 기준에서는 선택 및 건너뛴 결과가 표시되어야 하고, 블로킹 및 suspend 경로가 비교 가능해야 하며, 건너뛴 작업이 실행되지 않았음을 증명하는 최소 하나의 벤치마크가 필요했습니다.

## 결정

`BlockingLeaderContentionElectorBenchmark` 및 `SuspendLeaderContentionElectorBenchmark`에서 원격/공유 백엔드를 유지한 다음 로컬 기준선을 로컬 전용 클래스로 분할합니다. 로컬 선출기는 동일한 선출기 인스턴스가 프로세스 내 잠금 상태를 공유하는 경우에만 경합하므로 로컬을 원격/공유 팩토리 형태에 배치하면 잘못된 건너뛰기 동작이 발생합니다.

로컬 일시중단 `waitTime=0`가 로컬 병렬 행에서 의도적으로 제외되었습니다. 구현에서는 `withTimeoutOrNull(0)`를 사용하므로 의미 있는 경합이 측정되기 전에 즉각적인 무료 획득 시간이 초과될 수 있습니다. 원격 일시 중지 즉시 건너뛰기는 잠금 유지 시나리오의 적용을 받습니다.

## 결과

벤치마크 설정은 보류 잠금 건너뛰기 경로가 작업 본문을 실행하지 않고 건너뛴 결과를 반환하는지 검증합니다. 이제 README 및 벤치마크 보고서에는 원시 JSON, 렌더링된 SVG/PNG 차트, 전체 43행 스냅샷 테이블, 즉각적인 건너뛰기 대 긍정적 대기 경합에 대한 해석이 포함됩니다.

## 검증

- 벤치마크 공장을 수정하고 설정 문제를 일시 중지한 후 `:benchmark:compileBenchmarkKotlin`가 통과되었습니다.
- `:benchmark:benchmarkBenchmarkJar`는 JMH 병을 통과하고 생산했습니다.
- 로컬 전용 경합 연기 및 Lettuce 컨테이너 지원 건너뛰기 경로 연기가 통과되었습니다.
- 차트 SVG 파일은 `xmllint`로 검증되었고 CairoSVG로 렌더링되었으며 시각적으로 PNG로 검사되었습니다.

## 다음 시간

JMH에서 생성된 벤치마크 차트 JSON의 경우 `primaryMetric.params`가 아닌 최상위 `params`를 읽습니다. 키가 큰 README 차트에서는 범례 및 축 레이블 충돌을 놓치기 쉽기 때문에 수정 사항을 구문 분석한 후 차트를 다시 렌더링하고 시각적으로 검사합니다.
