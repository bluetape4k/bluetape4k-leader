# 0.4.0 개발 라인 오픈

## 맥락

`bluetape4k-leader` 0.3.0은 릴리스 워크플로를 통해 게시되었으며 BOM, `leader-core` 및 `leader-redis-redisson` POM에 대해 Maven Central에서 검증되었습니다.

## 결정

`develop`를 `baseVersion=0.4.0`를 사용하여 다음 마이너 라인으로 이동하고 `snapshotVersion=`를 비워 둡니다. 버그 수정이 아닌 작업은 계속해서 패치 릴리스가 아닌 마이너 릴리스로 그룹화되어야 합니다.

## 결과

로컬 Gradle 버전 검증은 이제 다음 개발 라인을 가리키며 README 종속성 좌표는 최신 안정 릴리스인 0.3.0을 계속 광고합니다.

## 검증

- GitHub 릴리스 워크플로 `26727897102`가 success적으로 완료되었습니다.
- Maven Central은 0.3.0 BOM, 코어 및 Redisson POM에 대해 HTTP 200을 반환했습니다.
- 버전 범프 후 `./gradlew properties --no-daemon | rg '^version:|^group:'`를 실행합니다.
