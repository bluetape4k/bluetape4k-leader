# 2026-05-27 0.3.0 개발 라인 오픈

## 맥락

`bluetape4k-leader` 0.2.2가 Maven Central에 게시되고 검증되었습니다. 다음 공개 마일스톤은 기능/디자인 작업이 포함된 0.3.0이며, 0.2.2 마일스톤에는 공개 문제가 없습니다.

## 결정

`baseVersion`를 `0.3.0`로 이동하고 git에서 `snapshotVersion=`를 비워 둡니다. 스냅샷 게시 워크플로는 여전히 `-PsnapshotVersion=-SNAPSHOT` 주입을 담당합니다.

## 결과

`develop`는 이제 로컬에서 다음 0.3.0 개발 라인으로 검증되지만 안정적인 릴리스 태그에는 여전히 빈 `snapshotVersion`와 정확한 `baseVersion` 일치가 필요합니다.

## 검증

경량 Gradle 속성 검사와 `git diff --check`를 실행합니다. 0.2.2가 최신 게시 릴리스로 남아 있으므로 README 안정적인 좌표 변경이 필요하지 않습니다.

## 향후 지침

안정적인 릴리스가 완료될 때마다 `baseVersion`를 다음 계획된 마일스톤으로 진행하고 게시 워크플로가 명시적으로 재정의하지 않는 한 `snapshotVersion=`를 비워 둡니다.
