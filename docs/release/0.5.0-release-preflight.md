## 릴리스 전에 첨부할 검증 증빙

- 정확한 candidate tag 커밋과 `git show-ref refs/tags/0.5.0` 출력.
- 전체 테스트의 clean 결과, production Detekt 결과, typecheck/compile 결과,
  `checkBinaryCompatibility` 보고서.
- 정확한 candidate 커밋에 대한 Java/Kotlin CodeQL 실행 URL. `actions`와
  `java-kotlin` job을 모두 포함해야 한다.
- 정확한 candidate tag 커밋을 기준으로 한 manual manifest 및
  release-contract 검증.
- 게시 및 GitHub Release URL, 이후 최종 마일스톤/이슈 상태 감사.
